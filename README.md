# banana converter

A tiny web page that turns a radiation dose into bananas.

Bananas have a bit of potassium-40 in them, so they're very slightly radioactive. People sometimes use "banana equivalent dose" to explain radiation without scaring anyone. One banana is about 0.1 µSv. I wanted to know how many bananas a chest X-ray is (about 1,000), so I made this.

## Using it

It's one HTML file. Open `index.html` in a browser and type a number. No install, no build, no dependencies.

If you want it online, GitHub Pages works fine: push it, then turn on Pages in the repo settings.

## Things to know

- This is a joke with real numbers in it. It is not a safety tool.
- Eating a banana doesn't actually give you 0.1 µSv. Your body keeps its potassium level about the same, so the extra doesn't stick around. The banana is just a handy unit.
- The example doses (dental X-ray, flight, CT scan, etc.) are rough averages from public sources like UNSCEAR. Real doses depend on the machine, the person and a lot of other things.
- If you're genuinely worried about a dose you got, talk to a doctor or your local radiation protection agency, not a banana page.
